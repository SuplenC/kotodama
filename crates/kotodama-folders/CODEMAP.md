# kotodama-folders code map

A Bundled extension. Maintained by hand: fix stale lines when you find them, and update this map in the PR that adds, moves or renames a module here. Paths are relative to `src/`. `manifest.toml` declares it; `src/main.rs` runs the protocol loop. See also the [root map](../../CODEMAP.md) and [GLOSSARY.md](../../GLOSSARY.md).

- `settings.rs`
- `projects.rs` (git repos, tms names)
- `scripts.rs` (executables and header options)
- `scan.rs` (`Scanner` thread)
- `items.rs`
- `launch.rs`
