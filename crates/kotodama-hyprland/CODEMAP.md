# kotodama-hyprland code map

A Bundled extension. Maintained by hand: fix stale lines when you find them, and update this map in the PR that adds, moves or renames a module here. Paths are relative to `src/`. `manifest.toml` declares it; `src/main.rs` runs the protocol loop on `kotodama-extension`: an `events` thread waits for Hyprland, follows its event socket, and waits again once it exits, and the windows and the binds each go out through a `SentItems::publish` of their own, so a window event sends only that window. Outside Hyprland it sends no Items, and says it can't do anything (`SentStatus`) until Hyprland runs. See also the [root map](../../CODEMAP.md) and [GLOSSARY.md](../../GLOSSARY.md).

- `hyprland.rs`: `Hyprland::candidates` (the instance `HYPRLAND_INSTANCE_SIGNATURE` names, then every other in `$XDG_RUNTIME_DIR/hypr/`, newest first), `connect` (the first whose event socket answers), `wait` (until one runs, on `kotodama_extension::runtime::wait_for`), `request` (one `.socket.sock` request, as `hyprctl` writes it), `dispatch`, `events`; `Error` (why Hyprland was not found or refused); `Events::next_change` (`.socket2.sock` lines).
- `events.rs`: `Change::parse` (the events that change an Item: `openwindow`, `closewindow`, `movewindowv2`, `windowtitlev2`, `configreloaded`).
- `windows.rs`: `Windows` (`from_clients` for `j/clients`, `apply`, `items`), `dispatch` (what each window Action runs), `ParseError`, `DispatchError`; `FOCUS`, `CLOSE`, `MOVE`, `FLOAT`, `WORKSPACE`.
- `binds.rs`: `Bind`, `parse` (`j/binds`), `ParseError`, `items` (binds with a description), `view` (the Shortcuts View, grouped by modifier), `find`, `shortcuts_item` (what `--view hyprland/shortcuts` names); `RUN`, `OPEN`, `VIEW`, `KIND`.
- `../tests/fixtures/`: `hyprctl binds -j` and `clients -j` output and an event stream, in Hyprland's formats. `../tests/binds.rs`, `../tests/windows.rs`: parsing, grouping and events against them. `../tests/extension.rs`: the Extension over stdio against a fake Hyprland serving both sockets, without Hyprland, one that starts after the Extension, and one that restarts.
- `../../../nix/tests/hyprland.nix`: the live tests, in a NixOS VM running Hyprland.
